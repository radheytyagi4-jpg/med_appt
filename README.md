# StayHealthy

A non-profit healthcare platform connecting patients in remote and underserved areas with certified doctors anytime, anywhere.

## Project Name
StayHealthy - Go Digital Healthcare Platform

## Setup Instructions

### Prerequisites
- Node.js v16+
- npm v8+

### Installation
```bash
git clone https://github.com/YOUR_USERNAME/stayhealthy.git
cd stayhealthy
npm install
npm start
```

### Production Build
```bash
npm run build
```

## Tech Stack
- React.js v18
- React Router DOM v6
- HTML5 / CSS3
